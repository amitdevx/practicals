## Question 3: Oral / Viva Questions & Answers [5 Marks]

### Q1. What is a Dendrogram?
**Answer:** A dendrogram is a tree-like diagram that records the sequences of merges or splits in hierarchical clustering.

### Q2. What is Feature Selection?
**Answer:** The process of selecting the most relevant features (variables) for use in model construction, which helps in improving model accuracy and reducing overfitting.

### Q3. What is PCA?
**Answer:** Principal Component Analysis is a dimensionality reduction technique that transforms a large set of variables into a smaller one that still contains most of the information.

### Q4. What is K-Means Clustering?
**Answer:** An unsupervised learning algorithm that groups data into K distinct non-overlapping subsets or clusters based on feature similarity.
