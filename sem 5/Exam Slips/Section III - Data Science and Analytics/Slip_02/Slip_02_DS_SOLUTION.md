## Question 3: Oral / Viva Questions & Answers [5 Marks]

### Q1. What is Data Discretization?
**Answer:** The process of converting continuous data into discrete categories or bins, making it easier for some machine learning models to analyze.

### Q2. What does Linear Regression do?
**Answer:** It models a linear relationship between an independent variable and a dependent variable to make continuous predictions.

### Q3. What is the Apriori Algorithm?
**Answer:** An algorithm used in market basket analysis to discover frequent itemsets and generate association rules in transactional databases.

### Q4. What is Support in Association Rule Mining?
**Answer:** Support is the proportion of transactions in the dataset that contain the itemset.

### Q5. Why is a scatter plot useful for Linear Regression?
**Answer:** A scatter plot visually reveals the correlation and linear trend between the predictor and the target variable, making it easier to see how well a line fits.
