# Slip 02 — Core Java and Web Technology-I Solution Guide

## Question 1: Armstrong Numbers in Given Range [15 Marks]

### Problem Statement
Write a Java Program to Display Armstrong Numbers Between range. Accept range from user.

### Concept & Algorithm
An Armstrong number is equal to the sum of its own digits raised to the power of the number of digits.

### Compilation & Execution
```bash
javac Slip_02_Q1.java
java Slip_02_Q1
```

### Sample Output
```text
Armstrong numbers between 1 and 500:
1 2 3 4 5 6 7 8 9 153 370 371 407
```

## Question 3: Oral / Viva Questions & Answers [5 Marks]

### Q1. What is an Armstrong number?
**Answer:** A number equal to the sum of cubes (or powers of total digits) of its individual digits.

### Q2. How do CSS selectors work?
**Answer:** CSS selectors target HTML elements based on element name, class (.class), ID (#id), or attributes.

### Q3. What is box model in CSS?
**Answer:** A box that wraps around every HTML element consisting of margins, borders, padding, and the actual content.

### Q4. What is JDK vs JRE?
**Answer:** JRE is the runtime environment that executes bytecode. JDK contains JRE plus development tools like javac.

### Q5. What is method overloading in Java?
**Answer:** Having multiple methods with the same name but different parameter lists in the same class.
