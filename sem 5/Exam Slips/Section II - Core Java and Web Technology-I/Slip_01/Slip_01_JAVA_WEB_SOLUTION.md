## Question 3: Oral / Viva Questions & Answers [5 Marks]

### Q1. What is the difference between an Array and an ArrayList in Java?
**Answer:** Arrays have fixed size and can hold primitives and objects. ArrayList is dynamic and holds only objects.

### Q2. What are semantic HTML5 elements?
**Answer:** Elements that convey their meaning to both browser and developer (e.g. <header>, <nav>, <article>, <footer>).

### Q3. What does the 'required' attribute do in HTML5?
**Answer:** It ensures that an input field cannot be submitted while empty.

### Q4. Why is main() declared as static in Java?
**Answer:** So the JVM can invoke it without instantiating the class.

### Q5. What is the JVM (Java Virtual Machine)?
**Answer:** An abstract computing machine that enables a computer to run Java bytecode.
