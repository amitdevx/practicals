## Question 1: Reverse File Contents [15 Marks]

### Problem Statement
Write a program to accept a text file from user and display contents in reverse order.

### Concept & Algorithm
Uses BufferedReader to read file contents, StringBuilder to reverse text, and prints the result.

### Compilation & Execution
```bash
javac Slip_05_Q1.java
java Slip_05_Q1
```

### Sample Output
```text
Enter filename: sample.txt
Reversed and Case Changed Content:
DLROw OLLEh
```

## Question 3: Oral / Viva Questions & Answers [5 Marks]

### Q1. What is BufferedReader in Java?
**Answer:** A class that reads text from a character-input stream, buffering characters to provide efficient reading.

### Q2. What is try-with-resources statement?
**Answer:** A try statement that declares one or more resources; ensures each resource is closed at the end of the statement.

### Q3. What is CSS transform?
**Answer:** A property that applies 2D or 3D transformations to an element (e.g. rotate, scale, translate, skew).

### Q4. What is the purpose of the alt attribute in <img>?
**Answer:** Provides alternative text for screen readers or when the image fails to load.

### Q5. What is FileReader vs FileInputStream?
**Answer:** FileReader reads character streams (text), while FileInputStream reads raw byte streams (binary).
