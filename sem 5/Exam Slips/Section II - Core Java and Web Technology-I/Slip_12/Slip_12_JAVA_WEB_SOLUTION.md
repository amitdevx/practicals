## Question 3: Oral / Viva Questions & Answers [5 Marks]

### Q1. How do you compile a Java class into a specific package directory?
**Answer:** Using javac -d . ClassName.java.

### Q2. What is default constructor?
**Answer:** A constructor with no parameters automatically provided by the compiler if no constructors are declared.

### Q3. What is string interpolation in JavaScript?
**Answer:** Evaluating expressions inside template strings using ${variable}.

### Q4. What is the difference between let and const in ES6?
**Answer:** let allows reassignment; const declares block-scoped read-only references.

### Q5. What is a pure function in JavaScript?
**Answer:** A function that always returns the same output for the same input and has no side effects.
